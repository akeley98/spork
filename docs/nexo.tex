\myBiggerTitle{``Myopic'' Scheduling Operators}

{\LARGE

What does a scheduling operator do?

\begin{itemize}
  \item Look for where the cursor is pointing in IR tree
  \item Analyze relevant variables
  \item Traverse tree many times to find properties of variables
  \item Error if rewrite unsafe
  \item Construct modified tree
  \item Throw away everything we found out!!!
\end{itemize}

\vfill

Next scheduling operator starts with NO USEFUL INFORMATION

\vfill

We do this back-to-back hundreds or thousands of times

\myBiggerTitle{Top-Level Idea: Imperative\texttt{++}}

{\LARGE

Multiple levels of partial functional specs for an assignment:

\begin{centering}

    After the assignment \texttt{A[...] = f(B[...])},

\end{centering}

\begin{itemize}
  \item None: we're too lazy to claim anything about the contents of \texttt{A}
  \item Hope: we believe without proof that \texttt{A} will hold ...
  \item Proof: prove, given \texttt{B}'s partial functional spec, that \texttt{A} will hold ...
  \item Testing: middle ground like Chexo?
\end{itemize}

\vfill

``Unsafe by default'': none of this is required to use the language

\vfill

BUT NOTE a proof for \texttt{A} can rely on hope for \texttt{B}, so you can take ``leaps of logic'' without abandoning all reasoning.

}
