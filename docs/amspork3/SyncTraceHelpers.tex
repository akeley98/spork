\caption{Synchronization Trace Helpers: $\sporktrAccessHelper, \sporkinstrBarrierHelper$.\\
For each accessed $\sporkx[\sporkz_i^*]$ in the window,
$\sporktrAccessHelper$ adds one or many $\sporkTrPreAccess$ events followed by one or many $\sporkTrPostAccess$ events;
``one'' is the convergent case
(an event includes all threads given by the $\sporktidMap$)
and ``many'' is the non-convergent case
(each thread gets its own events).
The former is less strict and models the implicit synchronization that instructions like
\texttt{mma.sync} and \texttt{shfl.sync} \cite{ptx} have when shuffling data between registers in a warp.
\\
$\sporkinstrBarrierHelper$ is defined for both alternatives of $\sporkfBarZ$ (Figure~\ref{fig:stmt}):
no trailing barrier expression, or \texttt{\color{barriercolor}>>$\sporkwz_\mathrm{bar}$}.
\\
The tuple comprehension has undefined order, but determinism can be forced with an arbitrary ordering, such as lexicographical.
The order makes no difference to trace analysis as it's performed for each array element independently.
