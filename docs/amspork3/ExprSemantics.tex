We assume constant arithmetic/logic, including externs, e.g. axioms \mbox{$\sporkRule{\sporkSub{2+2}{4}, \sporksigma \# \sporktr^*}$} and \mbox{$\sporkRule{\sporkSub{\texttt{exp2}(3)}{8}, \sporksigma \# \sporktr^*}$}.
Note \sporkERead\ cannot operate on \textsf{\#annotated} windows, which are first stepped by \sporkTrRead\ (Figure~\ref{fig:SyncTraceSemantics}).
