\caption{Window substitution $\sporks[\mathbf{\sporkv_1} \sporkWindowSub \mathbf{\sporkv_2}[\sporkcz_2^*]]$.
Window substitution steps each window $\sporkw$ in $\sporks$ fully according to the \textsc{W-Sub*} rules (with fixed $\mathbf{\sporkv_1},\mathbf{\sporkv_2}$).
These $\sporkw$ may be annotated ($\sporkw \# \sporkwinAnn$); the annotation is unchanged by the stepping.
Note $\sporke_\text{Lhi}$ is discarded; bounds-check is a separate step.
