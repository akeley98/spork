\caption{Window substitution $\sporks[\mathbf{\sporkx_1} \sporkWindowSub \mathbf{\sporkx_2}[\sporkcz_2^*]]$.
Window substitution steps each window $\sporkw$ in $\sporks$ fully according to the \textsc{W-Sub*} rules (with fixed $\mathbf{\sporkx_1},\mathbf{\sporkx_2}$).
These $\sporkw$ may be annotated ($\sporkw \# \sporkwinAnn$); the annotation is unchanged by the stepping.
Note $\sporkexpr_\mathrm{Lhi}$ is discarded; bounds-check is a separate step.
