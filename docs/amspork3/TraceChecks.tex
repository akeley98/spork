\magicSection{Trace Checks}{sec:TraceChecks}

We will view the trace events in a sequence $\sporktr^*$ as vertices in a graph (Section~\ref{sec:TraceVertices}).
There are edges defined between pairs of vertices as specified in Section~\ref{sec:TraceEdges}.

The infix ``checked trace concatenation operator'' is a partial function
$\sporkConcatChk: \sporkTr^* \times \sporkTr \rightharpoonup \sporkTr^*$.

$\sporktr^* \sporkConcatChk \sporktr_0$ is undefined when the check in
Section~\ref{sec:TraceConcatChk} fails; otherwise, it's the concatenation of $\sporktr^*, \sporktr_0$.

For clarity, we also define a ``raw'' trace concatenation operator
$\sporkConcatRaw: \sporkTr^* \times \sporkTr \to \sporkTr^*$
that omits the checking.

All trace concatenation functions are left associative and implicitly apply iteratively to a right-hand tuple argument, i.e.
\begin{gather}
  \sporktr^* \texttt{++} (\sporktr_0, \sporktr_1) = \sporktr^* \texttt{++} \sporktr_0 \texttt{++} \sporktr_1
\end{gather}
