\magicSection{Conventions}{sec:Conventions}

Concurrency-specific concepts are denoted with \textgpu{sansSerif} font.
With $n$ any subscript (possibly nothing), $\textgpu{sansSerif}_n$ denotes an unknown element of set \textgpu{SansSerif} (distinguished by case).
$\textgpu{sansSerif}_n^*$ denotes a tuple of $\textgpu{SansSerif}$ elements.
$\textgpu{SansSerif}_n$ ($n$ not empty) denotes an unknown subset of \textgpu{SansSerif}.

$\textgpu{sansSerif}_n:\textgpu{SansSerif}$ means ``let $\textgpu{sansSerif}_n$ be some member of $\textgpu{SansSerif}$'',\\
i.e. $\textgpu{sansSerif}_n$ is of type $\textgpu{SansSerif}$.\\
$\textgpu{SansSerif}_n:\mathcal{P}(\textgpu{SansSerif})$ means ``let $\textgpu{SansSerif}_n$ be some subset of $\textgpu{SansSerif}$''.

For non-concurrency-specific concepts, we use ordinary math script with the same casing convention, with some deviation based on custom (e.g. $\sporks{}: \sporkStmt{}$).
