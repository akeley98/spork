\magicSubsection{Commit Group Usage}{sec:CommitGroupUsage}

A barrier variable $z$ with commit group barrier mechanism may be declared with

\texttt{$z$: barrier[$e^*$] @ $\textit{mechanism}$}

\texttt{insert\_barrier\_alloc(\codecomment{...}, $z$, [$e^*$], $\textit{mechanism}$, None)}

where \texttt{\textit{mechanism}} is from one of the rows of this table:

\begin{tabular}{|l|l|l|l|}
\texttt{\textit{mechanism}} (def~\ref{sec:gBarrierMechanism}) & $\tau_s^\mathrm{pre}$ (def~\ref{sec:gFirstSyncTL}) & $\tau_s^\mathrm{post}$ (def~\ref{sec:gSecondSyncTL}) & $\tau_u$ (def~\ref{sec:gNativeUnit}) \\
\texttt{Sm80\_CommitGroup} & \texttt{Sm80\_cp\_async} & \texttt{cuda\_in\_order} & \texttt{cuda\_thread} \\
\texttt{Sm90\_TmaCommitGroup} & \texttt{tma\_to\_gmem\_async} & \texttt{cuda\_generic\_or\_async\_proxy} & \texttt{cuda\_warp} \\
\texttt{Sm90\_WgmmaCommitGroup} & \texttt{wgmma\_async} & \texttt{cuda\_generic\_or\_async\_proxy} & \texttt{cuda\_warpgroup} \\
\end{tabular}

In CUDA, the commit group is implicit state local to a thread, warp, or warpgroup; however in Exo-GPU we explicitly shard this barrier state onto the implicit thread state with distributed memory analysis.
This motivates the solitary barrier requirement (Section~\ref{sec:SolitaryBarrier}).

\mainKey{Statically-checked Requirements:}
\begin{itemize}
  \item Split barrier basic requirements (Section~\ref{sec:SplitBarrierBasic})
  \item Solitary barrier requirement (Section~\ref{sec:SolitaryBarrier})
  \item Barrier expressions (def~\ref{sec:gBarrierExpr}) must use only point indices, not intervals.
  \item The synchronization timelines $\tau_s^\mathrm{pre}$ and $\tau_s^\mathrm{post}$ used for \lighttt{Arrive} and \lighttt{Await}, respectively, must match the above table.
  \item \lighttt{Arrive} and \lighttt{Await} must be at $\tau_u$-scope as defined in the table (def~\ref{sec:gCollUnit}).
  \item The barrier allocation must pass distributed memory analysis (Section~\ref{sec:DistributedMemory}) with native unit $\tau_u$ as defined in the table.
  
\end{itemize}

\mainKey{Abstract Machine Requirements:} None
