\magicSubsection{\textrm{I}ota, mathbb-\textrm{I} ($\iota: \mathbb{I}$)}{sec:gIota}

$\mathbb{I}$ denotes the set of all task IDs (Section~\ref{sec:SyncSemanticsThreadMapping}) and $\iota$ is an element of that set.
When paired with a local thread index (def~\ref{sec:gLocalThreadIndex}), this forms a global thread ID $(\iota, n) \in \mathbb{G}$ (def~\ref{sec:gGlobalThreadID}).
