\magicSubsection{Checks on Free}{sec:ChecksOnFree}

Variables stored in shared memory that are not managed rign buffers (def~\ref{sec:gManagedRingBuffer}) must currently be allocated and freed at \lighttt{cuda\_cluster} scope (def~\ref{sec:gCollUnit}).
For such variables, upon free, we perform the same checks as for a non-atomic write-only access (Section~\ref{sec:ChecksOnMutate}) with
\begin{itemize}
  \item $g^* = g_{s^\#}(\iota, \sigma)$ being the thread collective assigned to execute the free statement (Section~\ref{sec:SyncSemanticsThreadMapping})
  \item $q^* = \{ \texttt{cuda\_in\_order\_qual} \}$ (def~\ref{sec:gQualTL})
  \item the convergence flag $t$ being false
\end{itemize}

When barrier variables are freed, the arrive count (Section~\ref{sec:SyncEnv}) must be 1 if the barrier mechanism has the one-shot arrive requirement (e.g. \lighttt{CudaClusterSync}, Section~\ref{sec:ClusterSyncUsage}).
Similarly, the await count must be 1 for the one-shot await requirement.
