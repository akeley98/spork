% no-VF: vocab split: in Python, InstrQuals.precondition_bits (core/memory.py, per MemWin x InstrTL) never contains atomic qual-tl (asserted). sync_check.py ORs in AccessInfo.atomicity qual-tl for atomic instr args, and only that OR'd set is camspork's precondition_qual_bits (the set actually checked; shown after "qual-tl:" in the missing tl-sig error). Define "precondition timeline set" as the camspork (OR'd) set; call the Python one something like the memory's base precondition set.

Set of qualitative timelines (def~\ref{sec:gQualTL}) associated with each read/mutate memory access.
This varies depending on the memory type accessed and the instruction used (Section~\ref{sec:InstrTL}).
In abstract machine semantics, this controls the checks upon reading (Section~\ref{sec:ChecksOnRead}) or mutating (Section~\ref{sec:ChecksOnMutate}) an array element.
