\magicSubsection{Pending Await ($\mathbb{P}$ / mathbb-P)}{sec:gPendingAwait}

Abstract machine concept (Section~\ref{sec:SyncSemantics}).
An ordered pair $(\mathbb{B} \times \mathbb{Z}^*) \times (\mathbb{Z} \cup \{\infty\})$ where the respective elements are
\begin{itemize}
  \item Barrier variable name \& array indices
  \item Minimum arrive count
\end{itemize}
The pending await function for a given visibility record (Section~\ref{sec:VisRecordState}) is defined by these ordered pairs.

Note the PLDI submission formulates this differently, as a function $p : \mathbb{B} \to \mathbb{Z}^* \to \mathcal{P}(\mathbb{N})$.
I later observed the power set $\mathcal{P}(\mathbb{N})$ is unnecessary, and we can just replace the set with the value of its minimum element ($\infty$ for an empty set).
