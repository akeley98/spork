\magicSection{Basic Idea}{sec:BasicIdea}

Managed ring buffer: One non-distributed dimension of the allocation is marked to be ring buffered by an integer \lighttt{ring\_depth}.
This is by extending \lighttt{LoopIR.Size} to have a \lighttt{SizeAnnotation?} member.
The extent of the managed ring-buffer dimension is transparently rewritten to \lighttt{ring\_depth}, and any corresponding indexing expression \lighttt{e} is transparently rewritten to \lighttt{(e + \emph{consumption}) \% ring\_depth}.

\magicSubsection{Alloc}{sec:Alloc}

Add \lighttt{flags} to allocation statements.
For now, only meaningful for \lighttt{BarrierEnvAlloc}, for one-shot arrive, one-shot await flags.

Add new\\
\lighttt{SetupSelfGuardedRingBuffer(e, e\_depth, managed\_ring\_buffer\_dim\_idx, barrier\_multicasts)},\\ \lighttt{SetupGuardedRingBuffer(g, e, e\_depth, managed\_ring\_buffer\_dim\_idx, barrier\_multicasts)}.

\begin{enumerate}
  \item Check \lighttt{g} size is prefix (or bigger) of \lighttt{e} size.
  \item Set \lighttt{free\_on\_arrive} for assignment record. \textbf{Require} that assignment record was null before.
  \item Add a new write visibility record with \lighttt{vis\_record\_before\_alloc\_flag} set and \lighttt{free\_on\_arrive}, initialized as follows:
  \item For self-guarded, \lighttt{e[..., k, ...]} has pending awaits for the multicast group of \lighttt{e[..., k - e\_depth, ...]}, and \lighttt{free\_on\_arrive} for the multicast group of itself, where \lighttt{...} are corresponding indices on non-managed-ring-buffer dimensions.
  \item For non-self-guarded, \lighttt{e[..., k, ...]} has pending awaits for the multicast group of \lighttt{g[..., k, ...]}, and \lighttt{free\_on\_arrive} for the multicast group of \lighttt{g[..., k + e\_depth, ...]}, where \lighttt{...} are corresponding indices on non-managed-ring-buffer dimensions.
\end{enumerate}
