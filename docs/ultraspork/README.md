Each section should be in its own file in order to optimize context window usage for AI assistants.

Please note the following:

* `../ultraspork.tex` is the top-level file.
  If you are AI, you may prefer to read the LaTeX source instead of the PDF.
  Follow the `\input` files to navigate the document.

* `Section~\ref{sec:*}` if it's a full section, should refer to a section stored in `*.tex`.
  NB sub-sections are currently not in their own file; you will have to guess where to look in that case.

* `Figure~\ref{fig:foo}`, if it refers to a code listing, should have the plain text code stored in `foo.0.txt`.
  Not all figures are code listings.

* `foo.[0-9].tex` files store said code formatted as LaTeX.
  If you are an AI assistant, you are advised NOT to read such files.
  They will be very hard to parse compared to the corresponding `foo.[0-9].txt` file.
  If you are a human, you are advised not to edit code tex or txt files by hand.
  They are generated by `../ultraspork_tex.sh`.
